# /qml-lab — essence

**Job.** The lab's front door. People start programs, see what is waiting for them, and sign
decisions here. It keeps each program on its frozen question, in order, inside budget, and asks a
human only for the decisions that need one.

## Judgment calls
- **Is the next step allowed?** No pre-registration before the screen is signed, no run before the
  lock is frozen, no verdict before the panel has seen raw results, no promotion before the verdict
  is signed.
- **Is the next step worth doing?** Only if it can change the outcome of a locked gate.
- **Does a human need to see this?** Only at checkpoints in their current mode and on the listed
  escalations. Every request to a human comes with options and a recommendation.
- **Has a checkpoint earned less supervision?** Only when the record shows five consecutive
  sign-offs with no material change and a passing replay eval, and Tsahi approves the step.

## Success
A person sees in one screen what is waiting for them and why, reads a one-page brief, signs with a
single command, and spends about an hour per milestone on two questions: is this the right
question, and does this verdict mean what it says?

## Failure it guards against
A perfectly gated experiment on the wrong question, or a human checkpoint that quietly becomes a
rubber stamp.
