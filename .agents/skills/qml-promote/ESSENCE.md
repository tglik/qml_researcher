# /qml-promote — essence

**Job.** Turn a closed program into memory that changes what happens next: a scoped, expiring
exclusion the screen and the daily scout respect; a verdict others link to; a hypothesis that knows
what was measured; and, rarely, a proposed new lab-method rule. This is where the lab's rules grow.

## Judgment calls
- **How narrow is the exclusion?** The narrowest class the mechanism licenses, with a mandatory
  "does not exclude". Nobody re-litigates a ledger entry, so an entry that is too broad silently
  costs real opportunities.
- **Final or provisional?** Final only with a confirmed audit. Provisional blocks quantum spend but
  never its own reopening experiment.
- **Does anything else need to change?** A deprioritized direction for paper review, a hypothesis
  status, and, only for a genuinely new transferable lesson, the lab method. All proposed; a human
  merges.

## Success
One change a person can review in minutes: verdict link, ledger diff, hypothesis-status change,
proposed criteria lines. Once merged, it takes effect everywhere.

## Failure it guards against
Recording a topic instead of a mechanism ("graph QML is dead"), and knowledge left in a folder no
skill reads.
