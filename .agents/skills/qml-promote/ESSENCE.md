# /qml-promote — essence

## What this skill is for
Turning a closed program into memory that changes what happens next — for the lab and for the
literature half of the researcher: a scoped, expiring exclusion the screen and the daily scout
will respect; a verdict entity others link to; a hypothesis card that knows what was measured;
and, rarely, a proposed new rule.

## The judgment calls it makes
- **How narrow is the exclusion?** The narrowest class the mechanism licenses, with a mandatory
  "does not exclude". Nobody re-litigates a ledger entry, so an entry that is too broad silently
  costs the lab real opportunities.
- **Final or provisional?** Final only with a confirmed audit; provisional blocks quantum spend but
  never its own reopening experiment.
- **Does anything else need to change?** A deprioritized direction in the domain criteria (so paper
  review inherits it), a hypothesis card's status, and — only for a genuinely new transferable
  rule — the lab method. All proposed; a human merges.

## What success looks like
One PR a person can review in minutes: the verdict link, the ledger diff, the hypothesis-status
change, and the proposed criteria lines — merged, it takes effect everywhere.

## The failure it guards against
Recording a topic instead of a mechanism ("graph QML is dead"), and letting knowledge stay in a
folder no skill reads.
